DATA PRINCIPLES

How CompanionAI should handle your data

Privacy is not just a setting. It should be part of how the system is designed.

01
Collect less

Only collect information needed for a feature to work.

02
Ask first

Optional sensors and external services should require explicit permission.

03
Explain clearly

The interface should tell you what a feature is doing and why.

04
Give control

You should be able to disable optional features and manage saved information.

🔐
A simple rule for sensitive information

Avoid storing passwords, financial information, authentication codes, or other highly sensitive information in CompanionAI memory.
