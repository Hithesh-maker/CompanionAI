# CompanionAI

Privacy-first supportive AI companion web application built with Node.js (native `node:http` + `node:sqlite`), salted `scrypt` authentication, HMAC-signed session tokens, user-controlled memory, emotion/crisis guardrails, and a light/dark responsive frontend.

## Run Locally
```bash
npm start
# Open http://localhost:4100
```

## Run Tests
```bash
npm test
```
